Build & run

How to compile this tree. Synthesized from BUILD_GUIDE.md and upstream-style doc/build-*.md. Update this page when a build succeeds or fails on a real machine.

Not yet verified on this recovery machine At first assessment, Git was missing from PATH and no successful local compile was re-proven. Treat the steps below as the intended path.

Recommended host

On Windows, WSL2 + Ubuntu 22.04 is the path of least pain for autotools Dogecoin Core. Native MSVC is not the primary build story for this tree.

Dependencies (Ubuntu/Debian style)

sudo apt update
sudo apt install -y build-essential libtool autotools-dev automake \
  pkg-config bsdmainutils python3 \
  libssl-dev libevent-dev \
  libboost-system-dev libboost-filesystem-dev libboost-chrono-dev \
  libboost-program-options-dev libboost-test-dev libboost-thread-dev \
  libdb5.3++-dev libdb5.3-dev \
  libqt5gui5 libqt5core5a libqt5dbus5 qttools5-dev qttools5-dev-tools \
  libqrencode-dev libzmq3-dev

Wallet needs Berkeley DB (this tree targets 5.3-class via DOGECOIN_FIND_BDB53). Disable wallet with --disable-wallet only if you intentionally skip it.

Configure & build

cd /path/to/dogedev   # or /mnt/c/dogedev from WSL
./autogen.sh
./configure --with-gui=qt5
# optional: ./configure --with-gui=qt5 --enable-debug
make -j$(nproc)

src/dogecoin-cli -regtest stop

# GUI (from desktop session / WSLg)
src/qt/dogecoin-qt -regtest
  • Theme switch does not crash
  • Overview shows balances (0 on fresh regtest)
  • RPC console answers getnetworkinfo
