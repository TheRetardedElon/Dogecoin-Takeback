Arcade (Retr-Doge Shibe Blaster)

Pure-Qt mini-game tab in Dogecoin Core Pro — entertainment shell only. No consensus impact, no EVM, no separate network protocol.

Shipped with 1.14.101 Qt only

What it is

  • Main-window tab: Arcade
  • Game: Retr-Doge Shibe Blaster (local canvas / widget)
  • Assets e.g. title art under Qt resources

Code surface

AreaLocation
Page / shellsrc/qt/arcadepage.*
Game widgetsrc/qt/arcadegamewidget.*
GUI wiringsrc/qt/dogecoingui.* (tab registration)

What it is not

  • Not a consensus or mining change
  • Not a payment rail (see Payment layer)
  • Not dependent on MemeStream or GPE
Product shell work sits beside Core Pro UI.
