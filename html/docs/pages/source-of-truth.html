Backup doctrine

Single-disk is how we got here After Git is restored: at least one remote (GitHub/GitLab) and one offline copy. Docs and diagrams live in the same repo as code.

How to update these docs

  • Edit HTML under html/docs/ (theme: assets/styles.css).
  • Add new pages under pages/ and register them in assets/nav.js (sidebar is auto-injected).
  • Record dates on dashboard / roadmap when status changes.
  • Prefer short factual updates over rewriting history.
  • Heavy product/engineering milestones also go in root DOGECOIN_CHANGELOG.md.
