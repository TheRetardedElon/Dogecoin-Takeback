Testnet mode

Same dogecoind, different chain. Testnet coins are worthless. The UI turns green (TUI) / Matrix (ImGui) so you cannot mistake it for mainnet.

Release: v1.14.104+ Updated: 2026-08-14
One dogecoind Stop the mainnet node first (File → Exit / tray Quit). The Hybrid Windows service DogecoinGPENode is mainnet-only. Testnet starts a separate process on the testnet3 datadir. Fast Sync CDN is mainnet-only — testnet syncs from testnet peers.

How to start

WhereWhat to click / type
Windows Start Menu Dogecoin Core Pro Testnet (Client / Hybrid) or Dogecoin Operator TUI Testnet (Server)
Desktop Dogecoin Core Pro Testnet → corepro-launch.exe --testnet
Linux applications menu Dogecoin Core Pro Testnet → dogecoin-core-pro --testnet
ImGui already open Options → Main → Testnet. Then stop the running node and start again.
Command line See flags below

Flags (all equivalent)

corepro-launch.exe --testnet
dogecoin-pro-gui.exe --ui gfx --testnet
gpenode-tui.exe --testnet
dogecoin-core-pro --testnet          # Linux launcher
dogecoind -testnet -server
dogecoin-cli -testnet getblockchaininfo

-testnet (single dash) is accepted everywhere Core already accepted it. --regtest / -regtest work the same way for local testing.

What does not change

  • Consensus rules are the testnet rules already in Core — we did not invent a chain.
  • Window X still hides to tray. File → Exit still stops this node cleanly.
  • RPC stays on 127.0.0.1. Cookie-first, then installer rpcuser/rpcpassword.
  • Optional Tor (Options → Privacy) is still P2P-only, never WebView.
