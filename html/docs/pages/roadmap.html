Roadmap — regain full control

Ordered plan. Each phase produces a durable artifact (tag, doc update, or green build) so progress is never only “in chat.”

Phase 0 — Control plane Done

  • Confirm tree at C:\dogedev
  • Stand up html/docs/ living documentation
  • Baseline rebrand residual scan
  • Install Git for Windows; restore from dogecoin-rebrand.bundle
  • History: 51dcd47 pre-rebrand → 975ef57 rebrand+themes
  • Commit docs + post-bundle deltas; junk blob removed
  • Push / mirror remote backup (never single-disk again)
  • Tag baseline-green-build after first green build

Phase 1 — Green build Done

  • WSL2 Ubuntu + deps (Boost, Qt5, BDB 5.3, libevent, …)
  • ./configure --with-gui=qt5 --enable-c++17 --with-incompatible-bdb
  • Build dogecoind, dogecoin-cli, dogecoin-tx, dogecoin-qt
  • Smoke: regtest getblockchaininfo
  • GUI theme switch smoke (daemon proven; GUI binary linked)
  • Record results on Build & run page

Phase 2 — Finish rebrand conversion Done (core)

  • T1 functional identifiers (conf, HMM, IPC, consensus macros, tests)
  • T1 user-facing strings / RPC help (bitcoins → dogecoins)
  • i18n context bitcoin-core → dogecoin-core (C++ + 64 .ts)
  • T3 header-guard mechanical pass (~200 files, BITCOIN_* → DOGECOIN_*)
  • Allowlist scan: copyrights / historical URLs still may say Bitcoin (intentional)

Phase 3 — UI solidification Core done

  • Delete dead *_fixed.h WIP headers
  • Single live theme path: ThemeManager (EnhancedThemeManager unlinked)
  • Fix status bar / modalOverlay init (was dead in unused function)
  • Restore setWalletActionsEnabled (was hard-disabled)
  • Unlink unused ModernMainWindow stack from Makefile (sources kept)
  • dogecoin-qt rebuild green
  • Screenshot gallery in docs (needs display session)
  • Network / peers polish (rebuild lost designs)

Phase 4 — External features Later

  • Meme Stream client integration (keys from GPE)
  • GPE / invoicing bridge (prefer outside consensus)
  • Optional GigaWallet / DogeConnect alignment

Phase 5 — Storage modernization Later

  • Evaluate libmdbx only with metrics
