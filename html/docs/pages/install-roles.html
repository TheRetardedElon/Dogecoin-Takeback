Every Windows setup and every .deb asks the same question. One dogecoind. Never two.

Markdown: doc/install-roles.md Release: v1.14.104 Updated: 2026-08-14

Windows

Asset: dogecoin-1.14.105-win64-setup-rpcsecure.exe on Takeback v1.14.105.

  • Unique RPC password page (no shared CHANGE_ME).
  • Qt is not packed. Start Menu “Dogecoin Core Pro” is the Hybrid launcher.
  • Hybrid default file hybrid-ui.txt = ask. Remember is opt-in.
  • Server/Hybrid register Windows service DogecoinGPENode (display name Dogecoin Core Pro) via gpenode-ops service-run. dogecoind is not a native SCM binary.
  • If dogecoind is already running, the service is installed but not started (one node).

Linux (apt)

Asset: dogecoin-core-pro_1.14.105-1_amd64.deb. Debconf asks Client / Server / Hybrid. Provides/Replaces dogecoin-gpenode. 

echo "dogecoin-core-pro dogecoin-core-pro/install-role select server" | sudo debconf-set-selections
sudo DEBIAN_FRONTEND=noninteractive apt-get install ./dogecoin-core-pro_1.14.105-1_amd64.deb

Reconfigure: sudo dpkg-reconfigure dogecoin-core-pro.

Hybrid picker

Opening Dogecoin Core Pro asks Desktop GUI vs Operator TUI unless hybrid-ui.txt (or /etc/dogecoin-core-pro/hybrid-ui) is gfx or tui. Change in GUI Options → Hybrid or TUI Settings → H. Direct exe launch with Hybrid+ask bounces back to the picker. The picker is corepro-launch.exe (WIN32, no console) — not PowerShell.

Close / tray / Exit

  • Window X and Hide / Minimize to tray hide the UI. The node stays up. One tray icon — the Desktop GUI. Do not also run gpenode-tray.
  • File → Exit and that icon's Quit and stop node stop the Windows service DogecoinGPENode if present (so it cannot restart the node), then RPC-stop dogecoind and wait for flush.
  • Hybrid: the same icon can Show Desktop GUI or Open Operator TUI while the node is still running.
  • Never force-kill dogecoind during IBD or flush.

Testnet shortcuts

  • Client / Hybrid Start Menu + desktop: Dogecoin Core Pro Testnet → corepro-launch.exe --testnet.
  • Server Start Menu: Dogecoin Operator TUI Testnet → gpenode-tui.exe --testnet.
  • Linux: applications menu entry + dogecoin-core-pro --testnet.
  • TUI goes green. ImGui uses the Matrix theme. RPC 44555, datadir testnet3.
  • Does not start or stop the mainnet service. Stop mainnet first (one dogecoind).
