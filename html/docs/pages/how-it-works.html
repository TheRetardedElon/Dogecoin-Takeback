How Dogecoin Core Pro works

End-user map of the 1.14.104 product. Same Dogecoin mainnet as official Core. This page is the topology that older Qt + “LevelDB-only” diagrams must match.

Release: v1.14.105 Updated: 2026-08-14
Unchanged AuxPoW, subsidy, scripts, P2P ports, and “is this a valid block?” stay in dogecoind. Other Core clients still peer with you.
Do not over-claim LevelDB is not deleted. It is still the default UTXO/index engine. Qt is not deleted from source. It is not shipped in 1.14.104 installers. Cloud is a CDN / archive dest, never a live chainstate/.

Testnet

Start Menu / desktop Dogecoin Core Pro Testnet, or corepro-launch.exe --testnet, dogecoin-pro-gui --ui gfx --testnet, gpenode-tui --testnet, dogecoin-cli -testnet. ImGui switches to Matrix (green). The TUI uses a green palette and a TESTNET header. Datadir is testnet3. The mainnet Windows service is not started. Full page: Testnet.

Meme Stream / Arcade / Privacy

  • Home keeps a compact Meme Stream rail (WebView of the GPE site).
  • The Meme Stream tab is Stream (full site) + Submit (≤ 69 KiB image + tip). It is not a second native feed.
  • Arcade is WebView of arcade.gopastearth.com.
  • Optional Tor (Options → Privacy) is P2P only. Drop tor.exe in Dogecoin\tor\. Not bundled. WebView stays on the normal web connection.

Disk vs cloud

Hot chainstate + wallet local only
→
Bootstrap CDN snapshot file
→
Warm blk*.dat prune
→
Cold archivepath copy
  • OneDrive / Drive / Dropbox / iCloud / pCloud / MEGA / Nextcloud = refused as live datadir.
  • CDN = HTTPS bytes + SHA-256 fail-closed.
  • -archivepath= copies finalized block files before prune deletes them. Not a second live node.
  • Operator /mnt/vfs (virtiofs) is archive/snapshot dest, not live LevelDB.

Fast Sync vs normal IBD

Normal:   peers → headers → blocks → UTXO  (days, full history)
Fast Sync: CDN file → SHA-256 → load UTXO at H → use wallet
           then background-prove history over P2P

Prefer an empty datadir. Do not Fast Sync mid-IBD+prune. Guide: Fast Sync.

What other Dogecoin nodes see

A peer. Same version handshake lineage (Shibetoshi). Same blocks. They never see ImGui, the TUI, hybrid-ui.txt, or MDBX. Storage engine is local.
